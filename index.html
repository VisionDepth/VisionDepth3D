The VisionDepth3D Method

A proprietary hybrid workflow for real-time and offline 2D to 3D conversion, developed for cinematic presentation and immersive VR viewing.

  • Depth-weighted continuous parallax shifting
  • Subject-aware zero parallax tracking
  • Edge-aware shift masking to reduce ghosting
  • Scene-aware parallax dampening
  • CUDA-accelerated stereo warping
  • Depth-of-field simulation with pixel healing

The method is documented for reference and educational review. Reuse, redistribution, or derivative publication of the method text is not permitted.

FAQ

Does it run on AMD or Apple GPUs?

VisionDepth3D can run on CPU across supported systems. GPU acceleration is currently focused on NVIDIA through CUDA and ONNX workflows. AMD users may be able to use alternative backends where available, while Apple Silicon support is planned for future development.

Can I use my own depth model?

Yes. Repository users can add compatible model weights to the appropriate folder and select them from within the application. Both PyTorch and ONNX-based workflows are supported, depending on the model.
