Official VisionDepth3D Free and Pro builds should only expose models marked as official build models in the current model registry.

The current official build registry contains:

## Non-Commercial and Review Models

Models marked as any of the following should not be advertised as official Free/Pro commercial-safe features unless permission or licensing has been verified:

- CC-BY-NC / NonCommercial
- research-only
- unclear license
- review pending
- missing license
- model weights with terms different from the source code license

Users are responsible for following the license terms of any third-party models they download, enable, or use with VisionDepth3D.
