# Legal Notices

This folder contains legal and attribution files for VisionDepth3D release builds.

Recommended files:

- `THIRD_PARTY_MODEL_ACKNOWLEDGMENTS.md`  
  Third-party model acknowledgments generated from the current model registry.

- `MODEL_LICENSE_NOTICE.md`  
  User-facing model license notice for documentation, installer packaging, and app About/Legal pages.

Before each release, review these files against the current `model_registry.json` and verify upstream model licenses.
