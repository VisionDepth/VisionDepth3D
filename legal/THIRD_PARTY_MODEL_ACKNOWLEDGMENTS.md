# Notes for Release Builds

- Keep this file updated whenever `model_registry.json` changes.
- If a model's source code license differs from its model weight license, treat the model weight license separately.
- Do not advertise non-commercial, research-only, unclear-license, or review-pending models as official Pro features.
- If VisionDepth3D bundles model code or weights directly, include the required upstream license text and notices in this `legal` folder.
- If VisionDepth3D only downloads a model from a third-party source at runtime, still provide clear attribution and link/reference information in the app or documentation.
